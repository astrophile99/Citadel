# Citadel North Star

## Our Mission Statement

> **Citadel exists to transform daily responsibilities into a meaningful ritual of hope.**
>
> **It helps people build consistency through encouragement, beauty, quiet companionship, and emotional attachment rather than pressure, guilt, fear, or addiction.**

---

## The Filter Rule

Every design decision, code contribution, asset creation, and notification string must pass this single question:

> **"Does this make the Commander feel welcomed, respected, and encouraged to return tomorrow without using anxiety or guilt?"**

*   If the answer is **Yes**, we build it.
*   If the answer is **No** (or it relies on FOMO, artificial streaks, or red badges), it does not belong in Citadel.

---

## Core Pillars

1.  **Compassionate Continuity**: No streaks. The Citadel is patient. Progress is permanently saved, and failure is treated as a natural sunset before another dawn.
2.  **Atmospheric Storytelling**: The world speaks through weather, dynamic time-of-day coloring, and subtle environmental shifts (e.g., hearth smoke, returning birds) rather than text-heavy UI or game stats.
3.  **Restraint over Bloat**: Every screen must breathe. Whitespace is a feature. We do not clutter the Commander's mind with features they do not need.
